## Problema / motivação

A P7/P8 precisam de NPCs para o mestre colocar em combate. Dois formatos: **template leve**
(stat block resumido, instanciado em quantidade — "Goblin ×4") e **NPC completo** (ficha
de `characters` com `is_npc = true`, passando pelo mesmo wizard/cálculos do PJ).

## Escopo

**Entra:**
- CRUD de `npc_templates` (nome, `hp_max`, `armor_class`, `initiative_mod`, `statblock` Json, `is_public`).
- Criação de template a partir de monstro do SRD (`srd_monsters`).
- NPC completo reaproveitando o wizard de P5, com `is_npc = true`; badge NPC em `/characters`.

**Não entra:**
- Instanciar template em sala (`room_temp_npcs`) — é da P7.
- Rolagem de iniciativa de NPC — P8.
